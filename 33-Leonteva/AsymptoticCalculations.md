# Асимптотика задач
**n** — длина массива, **k** — число особых элементов, **d** — разрядов числа (≤10 для `int`).

| №  | Задача                          | Время       | Память |
|----|---------------------------------|-------------|--------|
| 1  | Максимум и минимум              | O(n)        | O(1)   |
| 2  | Первое вхождение                | O(n)        | O(1)   |
| 3  | Подсчёт вхождений               | O(n)        | O(1)   |
| 4  | Все индексы элемента            | O(n)        | O(k)   |
| 5  | Сумма на чётных позициях        | O(n)        | O(1)   |
| 6  | Элементы больше среднего        | O(n)        | O(1)   |
| 7  | Второй максимум                 | O(n)        | O(1)   |
| 8  | Фильтрация по знаку             | O(n)        | O(n)   |
| 9  | Проверка отсортированности      | O(n)        | O(1)   |
| 10 | Последний кратный k             | O(n)        | O(1)   |
| 11 | Ближайший к среднему            | O(n)        | O(1)   |
| 12 | Пара с суммой s                 | O(n)        | O(n)   |
| 13 | Сортировка выбором              | O(n²)       | O(1)   |
| 14 | Сортировка вставками            | O(n²)       | O(1)   |
| 15 | Пузырёк + счёт обменов          | O(n²)       | O(1)   |
| 16 | Сортировка по модулю            | O(n²)       | O(1)   |
| 17 | Сортировка по сумме цифр        | O(n²·d)     | O(1)   |
| 18 | Сортировка только чётных        | O(n + k²)   | O(k)   |

**Итог:** №1–12 — линейные; №13–17 — квадратичные; №18 — зависит от числа чётных.
